## ✨ Project Description: Styling Fundamentals

This repository contains the files for **Homework 6**, a multi-page website project focused on introducing and implementing **Cascading Style Sheets (CSS)** for the first time. The goal was to transform a plain HTML structure into a visually appealing site.

This project was a major milestone, as it allowed me to practice the following key skills:

### Key Design & Structural Elements

* **Custom Styling:** Applying **color**, background images, and custom fonts across different pages using an external CSS file.
* **Navigation:** Creating a seamless user experience by linking multiple pages together (e.g., `index.html`, `about.html`, `contact.html`).
* **Visual Content:** Incorporating **images** using the `<img>` tag and ensuring they are displayed correctly with CSS.
* **Data Organization:** Implementing both **ordered lists** (`<ol>`), **unordered lists** (`<ul>`), and an HTML **table** to structure information clearly.

## 🚀 Getting Started (How to View the Project)

Since this project consists of static HTML and CSS files, viewing the website is simple and requires no special software.

1.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/YourUsername/clevas_HW6.git](https://github.com/YourUsername/clevas_HW6.git)
    ```
    *(Remember to replace `YourUsername`)*

2.  **Navigate to the Directory:**
    ```bash
    cd clevas_HW6
    ```

3.  **Open the Home Page:**
    * Find the file named `index.html` (or your main landing page file).
    * **Double-click** on this file to open the website in your default web browser (Chrome, Safari, Firefox, etc.).
    * From the home page, you can use the navigation links to explore the other pages, such as the table and the lists pages.

## 📁 File Structure

The project is organized into descriptive files:

* `index.html`: The home page of the website.
* `about.html`: A secondary page containing ordered and unordered lists.
* `data.html`: A page dedicated to displaying the HTML table.
* `style.css`: The external stylesheet used to apply all the color, layout, and visual effects.
* `images/`: A directory containing all the image assets used throughout the site.
* `README.md`: You are reading it!
